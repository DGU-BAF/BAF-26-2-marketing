## v5 통합 분석 요약

1. **배경 검증**: 2023→2025 관광지 관광객 도착 −29%, 도착 1건당 카드 소비 +34% → "더 오게"보다 "온 사람을 소비로 전환"이 중요한 국면
2. **통과형 판정**: 트래픽 3종(차량·관광지 관광객·SKT 방문) × 계산법 3종 = 9개 정의 합의 + 민감도 8가지 + 연도별 안정성 + 월 부트스트랩 1,000회. 원안 MI의 규모 편향(상관 0.61)을 −0.30으로 해소
3. **1차 군집 (환경 변수만)**: 공급규모 × 자연·체험 비중 → 대형 읍면 복합형 / 자연명소 집중형 / 도심·해안 명소형 (실루엣 0.56, 부트스트랩 ARI 0.88)
4. **소비 퍼널 분해**: 도착당 소비 = 로컬전환비(멈추는가) × 방문당 소비(쓰는가)
5. **레버 검증**: 28개 동 × 36개월 고정효과 패널 — 로컬 소비처 도착 10% ↑ → 관광객 카드 소비 약 +3.5% (p<0.001)
6. **사후 검증**: 분석에 안 쓴 2026 상반기에도 한경면 2위, 송산동 6위 유지
7. **스팟(관광지) 단위 분석**: 마을 관광 수요의 절반 이상을 차지하는 관광지 45곳 비교
   - 폭포·계곡형이 가장 통과형 (로컬전환비 중앙값 0.02) — 천지연·정방·천제연폭포 모두 0.00~0.04
   - 같은 종류 벤치마킹: 신창풍차해안도로 0.11 ↔ 도두무지개 2.29·하귀애월 1.70 / 정방폭포 0.01 ↔ 천지연폭포 서귀동 쪽 진입부 4.82
   - 공급 부족 vs 연결 부족 진단 + 주차장 좌표로 2km 이내 인접 상권 탐색 (정방폭포 ↔ 서귀동 도심 1.0km)
   - 확대 후보 5곳(곽지해수욕장·금오름·천지연폭포·천제연폭포·절물자연휴양림): 연 180억(패널 탄력성 0.36 기준) ~ 593억 원(상한)
8. **효과 측정 설계**: 이중차분(DiD) + 2023~2025 플라시보로 최소 검출 효과(MDE) 계산
   - 핀포인트 마을 로컬전환비는 사후 6개월이면 KPI 목표가 우연과 구분됨, 한경면 전체는 12개월
   - 송산동은 동 전체로는 효과가 묻혀 정방폭포 일대 마을 지표를 주 KPI로 사용
9. **대시보드**: 노트북 12장이 만든 데이터로 지도·타깃 처방·관광지 진단·월별 모니터링을 한 화면에 (노트북을 다시 돌리면 갱신)

| | 한경면 | 송산동 |
|---|---|---|
| 유형 / 벤치마킹 | 대형 읍면 복합형 / 조천읍 | 자연명소 집중형 / 대륜동 |
| 핀포인트 | 신창리 (신창풍차해안도로), 로컬전환비 0.11 | 정방폭포 일대 (법정동 동홍동), 로컬전환비 0.01 |
| 스팟 진단 | 신창풍차해안도로 — 공급 부족 (소비처 밀도 7곳/1만 건, 중앙값 21) | 정방폭포 — 공급 부족, 1.0km 옆 서귀동 도심 상권과 연결 가능 |
| 같은 종류 벤치마킹 | 도두무지개해안도로 2.29, 하귀애월해안도로 1.70 | 천지연폭포 서귀동 쪽 진입부 4.82 |
| 새는 업종 · 취약 시기 | 음식점업·소매업 · 2·3·6월 | 소매업·체험여가 · 5·6·7월 |
| 기대 추가 소비 (카드 결제 기준) | 연 37~146억 원 | 연 26~104억 원 |

효돈동은 강건한 통과형이지만 2026 상반기에 순위가 하락(11위)해 3순위 모니터링 대상.
