## 3. 데이터를 결합한 방식

- **조인 키**: 읍면동명 (읍면동코드는 파일마다 자릿수가 달라 이름으로 맞춤, 43개 동 전부 일치 확인)
- **시간 키**: 연월. 분석 2023.01~2025.12(36개월), 검증 2026.01~06(6개월)
- **결합 지표**
  - 통과형 합의점수 = 트래픽(1·2·4번) × 소비(3번)의 9개 정의 평균
  - 로컬전환비 = 4번의 로컬 소비처(식당·카페·로드샵) 도착 ÷ 관광지 도착
  - 도착당 소비 = 3번 관광객 소비 ÷ 4번 관광지 관광객 도착 = 로컬전환비 × 로컬 방문당 소비 (정확한 분해)
  - 체류율 = 2번 SKT 방문 ÷ 1번 차량 도착

## 4. 데이터를 다루며 확인한 점 (활용 과정의 충실성 근거)

| 발견 | 처리 |
|---|---|
| 소비 데이터의 약 49%가 도민 소비 | 관광객(내국인·외국인)만 사용 |
| 숙박업 카드 소비가 동마다 들쭉날쭉 (10개 동은 1% 미만, 온라인 선결제 추정) | 소비에서 숙박업 제외, 포함한 버전은 민감도 점검에만 사용 |
| 인기장소 카테고리 542종에 공항·주유소·병원 등 비관광 목적지 포함 | 목록 기반으로 관광지 / 로컬 소비처 / 숙박 / 이동·생활로 명시 분류, 분류표 저장 |
| 플랫폼 파일이 2026.06까지 갱신됨 | 2023~2025로 분석, 2026 상반기는 사후 검증용으로 분리 |
| 같은 관광지가 주소에 따라 두 마을로 잡힘 (예: 천지연폭포 서홍동·서귀동) | 마을 단위로 따로 계산 → 상권과 이어진 쪽의 전환비가 높다는 근거로 활용 |
